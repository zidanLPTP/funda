# Rencana Implementasi: Tahap 1 — Fondasi (Funda)

> **Untuk agent:** Gunakan `superpowers:executing-plans` untuk mengimplementasikan rencana ini tugas demi tugas.

**Goal:** Menyiapkan kerangka proyek Flutter "Funda" yang berjalan dan siap dibangun fitur di atasnya: struktur, tema soft bento, komponen dasar, navigasi 4 tab, database Drift + migrasi bertingkat, util Rupiah, pengujian, galeri komponen, dokumentasi, dan remote git.

**Arsitektur:** Menggunakan Flutter Material 3 bertema soft bento, state management Riverpod, routing deklaratif GoRouter, penyimpanan lokal SQLite via Drift dengan skema migrasi bertingkat, dan fungsi murni teruji untuk util keuangan.

**Tech Stack:** Flutter 3.38.3, Dart 3.10.1, flutter_riverpod, go_router, drift, sqlite3_flutter_libs, path_provider, intl, flutter_lints.

**Spec:** `spec.md`, `agent.md`, `styleguide.md`.

## Global Constraints
- Bahasa: SEMUA kode baru, commit, nama file/folder, kelas, variabel, dan dokumentasi WAJIB bahasa Indonesia.
- Uang = `int` Rupiah (dilarang menggunakan `double`).
- Tampilan: Soft Bento UI sesuai token di `styleguide.md`, tanpa nilai warna/ukuran hard-coded di komponen.
- Font: Plus Jakarta Sans dibundel di aset lokal.
- Aksesibilitas: target sentuh ≥ 48dp, label `Semantics`.
