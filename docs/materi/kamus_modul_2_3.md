# Kamus Tambahan Modul 2 & 3

| Istilah | Arti | Contoh Rupiah |
| :--- | :--- | :--- |
| tenggat | Batas waktu yang kamu tetapkan untuk mencapai sebuah tujuan. | Tenggat 12 bulan untuk target Rp6.000.000. |
| setoran | Uang yang kamu sisihkan ke sebuah tujuan pada satu kali pengisian atau tiap bulan. | Setoran Rp250.000 per bulan. |
| kantong | Penanda bagian saldo sebuah dompet untuk tujuan tertentu. Uangnya tidak berpindah. | Kantong Laptop Skripsi berisi Rp500.000 dari dompet bank. |
| saldo bebas | Saldo dompet yang belum ditandai untuk tujuan apa pun. | Saldo dompet Rp1.000.000 dengan kantong Rp200.000 berarti saldo bebas Rp800.000. |
| pengeluaran wajib | Pengeluaran yang tetap harus dibayar saat keadaan sulit, yaitu kebutuhan pokok dan cicilan. | Kos Rp900.000, makan Rp600.000, dan cicilan Rp200.000. |
| tonggak | Target kecil di tengah jalan menuju target besar. | Tonggak pertama dana darurat: satu bulan pengeluaran wajib, Rp1.900.000. |
